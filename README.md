# Preet Pratap Singh Bhati - Portfolio

Welcome to my developer portfolio! This repository contains the source code for my interactive portfolio showcase, featuring modern web aesthetics, interactive project hubs, and detailed documentation pages.

Live Demo: [https://preetthakur25.github.io/](https://preetthakur25.github.io/)

## 🚀 Features

- **Modern Glassmorphic UI**: High-end dark theme with fluid gradient typography, glowing accents, and smooth micro-animations.
- **Categorized Showcase Pages**: Dedicated hubs for AI/ML projects, Autonomous Agents, and Enterprise Web Applications.
- **Interactive Markdown Viewer**: Markdown viewer component for rendering detailed project documentation (`project.html`).
- **Interactive Terminal**: Custom web CLI interface allowing users to explore skills, projects, contact info, and Easter eggs interactively.
- **Responsive Layout**: Designed for mobile, tablet, and desktop screens.

## 🛠️ Built With

- **HTML5 & Vanilla CSS3**: Custom design tokens, CSS grid/flexbox, animations, glassmorphism.
- **Vanilla JavaScript**: Dynamic project loading, terminal emulator, dark/light theme options, and custom UI interactions.
- **Marked.js & Highlight.js**: Syntax highlighted markdown project rendering.

## 📂 Project Structure

```
├── index.html            # Main Landing / Overview Page
├── ml.html               # Machine Learning & Deep Learning Showcase
├── agents.html           # Autonomous AI Agents & Multi-Agent Frameworks
├── apps.html             # Full-Stack & Enterprise Web Applications
├── project.html          # Detailed Markdown Documentation Viewer
├── style.css             # Main stylesheet & design system
├── script.js            # Core interactive logic & Terminal emulator
├── generate_pages.py     # Static site generator helper script
├── README_*.md           # Documentation files for individual projects
└── resume.pdf            # PDF Resume
```

## 💻 Local Development

Simply open `index.html` in your browser, or serve using any static web server (e.g. VS Code Live Server or Python `http.server`):

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
